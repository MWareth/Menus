Admin recovery

Forgot the admin PIN? Set a new one here with your recovery key.

  1. Cloudflare dashboard → Workers → dees-stock → Settings → Variables and secrets.
  2. Add a secret named ADMIN_RECOVERY with a long password only you know (12+ characters). Deploy.
  3. Type that password below and choose a new PIN.
  4. When it works, delete the secret again.

New PIN saved. Log in with it now.

Now delete the ADMIN_RECOVERY secret in Cloudflare so this page switches off again.
